# Especificación de requisitos — Menu

**Revisión:** 8 — 2026-09-13

Esta revisión formaliza como requisitos de consumidor las obligaciones confirmadas de las UI de mesero y administrador. La propiedad de Menu no se transfiere a Sala, Orders, Inventory, Billing ni a los proveedores de imágenes; las proyecciones externas faltantes permanecen abiertas en OPEN-011 a OPEN-019. Los criterios de aceptación no son resultados de pruebas de implementación.
