# E-02 — Consultar catálogo de MenuItem

## Endpoint versionado

`GET /v1/restaurants/{restaurantId}/catalog/menu-items`

Proveedor: **Menu**. Dirección: **entrada**. Host: el de Menu; no el de otro servicio.

## Autorización y headers

Permiso requerido: `menu:catalog:read` y acceso al restaurante de la ruta. Identidad humana o de servicio autenticada según [política aprobada](../../02-convenciones.md). Sin credencial válida: 401; sin permiso/ámbito: 403. `Authorization: Bearer <credencial>` y `Accept: application/json`.

## Parámetros

Cada parámetro entre llaves en la ruta es string opaco obligatorio, no vacío. IDs deben pertenecer al restaurante. Versiones se codifican como segmento URL, preservando zona y contador. Query: menuId requerido; categoryId opcional exacto; query opcional coincidencia parcial de nombre sin distinguir mayúsculas; cursor y limit como E-01.

## Body

Sin body. Un cuerpo en GET se rechaza con 400.

## Respuesta

`200` con `Content-Type: application/json`. Esquema: [CatalogPage](../../schemas/CatalogPage.schema.json).

`Cache-Control: no-store`. 

```json
{
  "items": [
    {
      "menuItemId": "mi-agua",
      "menuItemVersion": "1_2026-09-11T15:47:26-06:00",
      "name": "Agua",
      "description": "Agua embotellada",
      "imageRef": null,
      "categoryId": "bebidas",
      "eligible": true,
      "fromPrice": {
        "amount": "25.00",
        "currency": "MXN"
      }
    }
  ],
  "nextCursor": null
}
```

## Comportamiento y errores

Solo MenuItem ACTIVE. Puede aparecer no disponible con eligible=false y fromPrice=null. El mínimo usa exclusivamente variantes elegibles. Orden nombre y menuItemId. No divulga stock exacto.

Errores específicos: 404 MENU_NOT_FOUND; 409 CURSOR_EXPIRED. Además: 400 formato/headers, 401/403 autorización, 500 INTERNAL_ERROR y 503 MENU_UNAVAILABLE; mutaciones pueden devolver 409 IDEMPOTENCY_CONFLICT y ediciones 412 REVISION_CONFLICT. Todos usan [Error](../../schemas/Error.schema.json), nunca un resultado exitoso vacío para ocultar el fallo.
