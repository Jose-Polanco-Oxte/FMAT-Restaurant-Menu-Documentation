# E-13 — Editar receta

## Endpoint versionado

`PUT /v1/restaurants/{restaurantId}/recipes/{recipeId}`

Proveedor: **Menu**. Dirección: **entrada**. Host: el de Menu; no el de otro servicio.

## Autorización y headers

Permiso requerido: `menu:recipe:write` y acceso al restaurante de la ruta. Identidad humana o de servicio autenticada según [política aprobada](../../02-convenciones.md). Sin credencial válida: 401; sin permiso/ámbito: 403. `Authorization: Bearer <credencial>` y `Accept: application/json`. `Content-Type: application/json`. `Idempotency-Key` obligatorio. `If-Match` obligatorio con ETag de la lectura actual.

## Parámetros

Cada parámetro entre llaves en la ruta es string opaco obligatorio, no vacío. IDs deben pertenecer al restaurante. Versiones se codifican como segmento URL, preservando zona y contador. Query: Ninguno.

## Body

Esquema completo: [RecipeWrite](../../schemas/RecipeWrite.schema.json). Todos los campos requeridos están enumerados en `required`; los tipos anidados se enlazan mediante `$ref`.

```json
{
  "name": "Preparación base",
  "components": [
    {
      "inventoryItemId": "i-queso",
      "quantity": "30",
      "unit": "g"
    }
  ]
}
```

## Respuesta

`200` con `Content-Type: application/json`. Esquema: [RecipeDefinition](../../schemas/RecipeDefinition.schema.json).

`ETag` de la representación actual en respuesta. 

```json
{
  "recipeId": "rec-1",
  "recipeVersion": "1_2026-09-11T15:47:26-06:00",
  "name": "Preparación base",
  "components": [
    {
      "inventoryItemId": "i-queso",
      "quantity": "30",
      "unit": "g"
    }
  ]
}
```

## Comportamiento y errores

Crea revisión inmutable solo si cambia nombre/composición. Adopción en una variante requiere edición explícita de MenuItem.

Errores específicos: 404 NOT_FOUND; 422 DOMAIN_VALIDATION. Además: 400 formato/headers, 401/403 autorización, 500 INTERNAL_ERROR y 503 MENU_UNAVAILABLE; mutaciones pueden devolver 409 IDEMPOTENCY_CONFLICT y ediciones 412 REVISION_CONFLICT. Todos usan [Error](../../schemas/Error.schema.json), nunca un resultado exitoso vacío para ocultar el fallo.
