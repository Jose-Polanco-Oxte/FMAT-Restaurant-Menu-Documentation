# E-17 — Copiar o asignar configuraciones

## Endpoint versionado

`POST /v1/restaurants/{restaurantId}/menu-items/{menuItemId}/configuration-operations`

Proveedor: **Menu**. Dirección: **entrada**. Host: el de Menu; no el de otro servicio.

## Autorización y headers

Permiso requerido: `menu:definition:write` y acceso al restaurante de la ruta. Identidad humana o de servicio autenticada según [política aprobada](../../02-convenciones.md). Sin credencial válida: 401; sin permiso/ámbito: 403. `Authorization: Bearer <credencial>` y `Accept: application/json`. `Content-Type: application/json`. `Idempotency-Key` obligatorio. `If-Match` obligatorio con ETag de la lectura actual.

## Parámetros

Cada parámetro entre llaves en la ruta es string opaco obligatorio, no vacío. IDs deben pertenecer al restaurante. Versiones se codifican como segmento URL, preservando zona y contador. Query: Ninguno.

## Body

Esquema completo: [ConfigurationOperation](../../schemas/ConfigurationOperation.schema.json). Todos los campos requeridos están enumerados en `required`; los tipos anidados se enlazan mediante `$ref`.

```json
{
  "kind": "COPY_MODIFIERS",
  "sourceVariantId": "v-small",
  "targetVariantIds": [
    "v-large"
  ],
  "configIds": [
    "cfg-1"
  ],
  "conflictPolicy": "FAIL",
  "dryRun": true
}
```

## Respuesta

`200` con `Content-Type: application/json`. Esquema: [ConfigurationResult](../../schemas/ConfigurationResult.schema.json).

`ETag` de la representación actual en respuesta. 

```json
{
  "applied": false,
  "menuItemVersion": "1_2026-09-11T15:47:26-06:00",
  "mappings": [],
  "violations": [],
  "warnings": []
}
```

## Comportamiento y errores

Tres variantes de body discriminadas por kind. dryRun=true simula y retorna applied=false, sin mutar. dryRun=false aplica todo-o-nada al mismo MenuItem. Mapeos vacíos en simulación; se asignan IDs nuevos al aplicar. Las reglas completas se encuentran en operaciones de configuración. La simulación no garantiza commit posterior.

Errores específicos: 404 NOT_FOUND; 409 ACTIVE_DEPENDENCY; 422 CROSS_MENU_ITEM_COPY; 422 CONFIGURATION_CONFLICT. Además: 400 formato/headers, 401/403 autorización, 500 INTERNAL_ERROR y 503 MENU_UNAVAILABLE; mutaciones pueden devolver 409 IDEMPOTENCY_CONFLICT y ediciones 412 REVISION_CONFLICT. Todos usan [Error](../../schemas/Error.schema.json), nunca un resultado exitoso vacío para ocultar el fallo.
