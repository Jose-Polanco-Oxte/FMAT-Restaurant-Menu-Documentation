# E-21 — Confirmar revisión de combo

## Endpoint versionado

`POST /v1/restaurants/{restaurantId}/menu-items/{menuItemId}/review-confirmations`

Proveedor: Menu. Dirección: entrada.

## Autorización y headers

Bearer válido, permiso `menu:definition:write` y ámbito restaurante. 401 sin identidad válida; 403 sin permiso/ámbito. JSON UTF-8. E-21 requiere Idempotency-Key; no requiere If-Match comercial, porque confirma observaciones y no edita la definición.

## Parámetros

restaurantId y menuItemId son IDs opacos no vacíos. MenuItem debe pertenecer al restaurante autorizado y ser COMBO. Sin parámetros query. Cada configurationId del body pertenece a ese combo y aparece una sola vez.

## Body

[Schema](../../schemas/ReviewConfirmation.schema.json)

```json
{
  "configurations": [
    {
      "configurationId": "cfg-combo",
      "reviewToken": "review-observed-1"
    }
  ]
}
```

## Respuesta

200. [Schema](../../schemas/ReviewReceipt.schema.json). Cache-Control: no-store.

```json
{
  "menuItemId": "mi-combo",
  "reviewId": "review-1",
  "actorId": "admin-1",
  "reviewedAt": "2026-09-12T16:00:00Z",
  "configurations": [
    {
      "configurationId": "cfg-combo",
      "acknowledgedChangeIds": [
        "change-1"
      ],
      "state": "UP_TO_DATE"
    }
  ]
}
```

## Comportamiento y errores

Aplicar la [semántica de revisión](../../05-revision-combos.md). 404 MenuItem inexistente en el restaurante autorizado; 422 no COMBO, configuración ajena/repetida o token ajeno/inválido; 409 IDEMPOTENCY_CONFLICT, IDEMPOTENCY_RESULT_EXPIRED o REVIEW_TOKEN_EXPIRED; 400 formato/headers inválidos; 500/503 según convenciones. Errores usan Error con violations. Validar todos los tokens antes de registrar efectos: no hay confirmación parcial por error de entrada. Confirmar únicamente cambios observados y devolver estado posterior por configuración; puede permanecer REVIEW_REQUIRED. El recibo completo se conserva siete días aunque cambie después el estado; exponer Idempotency-Result-Expires-At según convenciones; refrescar E-20 para ver el estado actual.
