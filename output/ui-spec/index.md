# Especificación de datos para UI

## Documentos

- [Especificación actual de vistas y datos](./ui-data-spec.md)
- [Supuestos externos para la UI](./external-assumptions.md)
- [Versión anterior, solo como antecedente](./old-version/secuence-v5.md)

La especificación actual no describe flujos de navegación. Registra vistas, estados visuales, datos representados, origen de cada dato y límites de los contratos disponibles. Incluye requisitos de UI confirmados para mesas, catálogo, clasificación visual, preorden, administración, archivado suave, wizard y revisión; las incertidumbres restantes se limitan a dependencias externas. La formalización normativa está sincronizada con la ERS canónica, revisión 8.

## Autoridad

La fuente principal es la ERS canónica de Menu y el paquete actual de interfaces. La versión anterior no es normativa. Los datos de Sala y Orders se identifican como dependencias externas porque no están definidos en este repositorio.
